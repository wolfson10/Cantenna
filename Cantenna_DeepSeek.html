Reference Formulas

Wavelength: λ = c / f
Where c = 3×10⁸ m/s (speed of light), f = 2.4×10⁹ Hz
Cutoff Frequency: fc = (1.8412 × c) / (π × D)
Minimum frequency for TE₁₁ mode propagation in circular waveguide
Guide Wavelength: λg = λ / √(1 − (fc/f)²)
Effective wavelength inside the waveguide (always longer than free-space λ)
Probe Length: Lp ≈ λ/4 × correction_factor
Quarter-wave monopole with empirical diameter correction
Probe Position: Dp = λg / 4
Quarter-wavelength from back wall for optimal standing wave
